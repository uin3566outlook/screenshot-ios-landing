ภาพรวม

ClipShare ช่วยจับภาพ ครอบตัด ใส่คำอธิบาย บันทึก และแชร์ภาพบน iPhone นโยบายนี้ครอบคลุมแอป iOS และหน้าเอกสารกฎหมายสาธารณะ ผู้ให้บริการคือ Huanwei Ye หากมีคำถามด้านความเป็นส่วนตัว ติดต่อ airproductlab@gmail.com

ภาพและการประมวลผลในอุปกรณ์

ภาพที่เลือกผ่านตัวเลือกรูปภาพของระบบหรือรับจากคำสั่งลัด Capture and Share จะประมวลผลในอุปกรณ์ การครอบตัด วาด เพิ่มข้อความ ลูกศร ปิดทับ และส่งออกจะไม่อัปโหลดภาพไปยังเซิร์ฟเวอร์ผู้พัฒนา แอปเก็บไฟล์ทำงานชั่วคราวเพื่อแก้ไขหรือแชร์ แล้วลบเมื่อไม่จำเป็น เมื่อเปิดแอปจะล้างไฟล์ภาพชั่วคราวของตนที่ตกค้างเกิน 15 นาที สำเนาที่คุณเลือกบันทึกในรูปภาพหรือส่งไปแอปอื่นอยู่ภายใต้การจัดการของคุณที่ปลายทางนั้น

สิทธิ์กล้อง

แอปขอสิทธิ์กล้องเฉพาะเมื่อคุณเลือกถ่ายภาพ จากนั้นเปิดตัวแก้ไขทันที ภาพต้นฉบับอยู่ในหน่วยความจำสำหรับการแก้ไขรอบนั้น และไม่บันทึกในรูปภาพหรือประวัติโดยอัตโนมัติ เมื่อปิดตัวแก้ไขจะคืนหน่วยความจำ เฉพาะผลลัพธ์ที่คุณเลือกบันทึกหรือแชร์สำเร็จเท่านั้นที่อาจเก็บไว้ตามรายละเอียดด้านล่าง กล้องไม่ขอสิทธิ์ไมโครโฟนหรือตำแหน่งที่ตั้ง

สิทธิ์รูปภาพ

การเลือกภาพใช้ตัวเลือกรูปภาพของ Apple โดยไม่ต้องเข้าถึงทั้งคลัง แอปขอสิทธิ์เพิ่มรูปภาพอย่างเดียวเมื่อคุณแตะบันทึกไปยังรูปภาพ แล้วบันทึกภาพที่แก้ไขลงคลัง คุณปฏิเสธหรือเปลี่ยนสิทธิ์ในการตั้งค่า iOS ได้ โดยยังแชร์ภาพได้

การวางภาพ

หน้าหลักใช้ปุ่มวางของระบบ Apple เพื่อรับภาพเมื่อคุณแตะ หากเปิดลิงก์วางและแก้ไขจากวิดเจ็ตเวอร์ชันก่อนหน้า แอปจะอ่านคลิปบอร์ดหลังเข้าสู่เบื้องหน้า แล้วเปิดภาพที่คัดลอกในตัวแก้ไข iOS อาจขอให้อนุญาตวางจากแอปอื่น การเปิดหรือกลับเข้าแอปตามปกติจะไม่นำเข้าคลิปบอร์ดอัตโนมัติ ตัววิดเจ็ตไม่อ่านคลิปบอร์ด ภาพต้นฉบับที่วางใช้ในหน่วยความจำสำหรับการแก้ไขรอบนี้ และไม่บันทึกในรูปภาพหรือประวัติอัตโนมัติ เฉพาะผลลัพธ์ที่คุณเลือกบันทึกหรือแชร์สำเร็จเท่านั้นที่อาจเก็บไว้ตามกฎการเก็บข้อมูล การวางไม่ขอสิทธิ์รูปภาพหรือกล้อง

การปิดทับเองและคำอธิบายที่บันทึก

คุณปิดทับพื้นที่เองด้วยโมเสก เบลอ หรือสีทึบได้ การแก้ไขทำในอุปกรณ์ ขณะนี้การปิดทับอัตโนมัติใช้ไม่ได้ ไม่มีการสแกนภาพหรือเรียกโมเดล PII พื้นที่ปิดทับและผลการตรวจที่เคยบันทึกยังเป็นคำอธิบายที่แก้ไขได้ รายการโปรดอาจเก็บประเภท พิกัด และสถานะตรวจ แต่ไม่เก็บข้อความที่รู้จำ ประวัติเก็บภาพผลลัพธ์ที่รวมชั้นการแก้ไขแล้วตามกฎด้านล่าง

ข้อมูลที่เก็บในอุปกรณ์

แอปเก็บรูปแบบหน้าจอ สถานะตั้งค่าจับภาพด่วน และรายการโปรดไว้ในพื้นที่แอปบนเครื่อง รายการโปรดอาจมีพิกัดครอบตัด เอฟเฟ็กต์คำอธิบาย ชื่อ และข้อความที่พิมพ์ แต่ไม่มีภาพต้นฉบับ หลังแชร์สำเร็จหรือบันทึกในรูปภาพ แอปจะเก็บภาพที่แก้ไขในประวัติส่วนตัวบนเครื่องด้วย ประวัติจุ 100 MB ไม่จำกัดจำนวนภาพและจะลบภาพเก่าเมื่อเกินความจุ คุณลบทีละรายการได้ ผู้พัฒนาไม่ได้รับเนื้อหาเหล่านี้ ล้างรายการโปรดได้ในการตั้งค่า การถอนแอปจะลบพื้นที่แอปในเครื่องตามกลไก iOS การลบประวัติหรือแอปไม่ลบสำเนาที่เคยบันทึกในรูปภาพหรือแชร์ไปแล้ว

การแชร์และบุคคลที่สาม

เมื่อแตะแชร์ iOS จะแสดงปลายทางที่ใช้ได้ ภาพที่แก้ไขส่งไปเฉพาะปลายทางที่คุณเลือก ผู้ให้บริการปลายทางจัดการภาพตามข้อกำหนดและนโยบายความเป็นส่วนตัวของตน ClipShare ไม่เก็บรายชื่อผู้รับ แอปไม่มีระบบบัญชี โฆษณา SDK วิเคราะห์บุคคลที่สาม หรือการติดตามข้ามแอป

หน้าเอกสารกฎหมายสาธารณะ

แอปโหลดนโยบายและข้อกำหนดล่าสุดจาก GitHub Pages ผ่าน HTTPS ได้ ผู้พัฒนาไม่เพิ่มคุกกี้ แบบฟอร์ม สคริปต์วิเคราะห์ หรือโฆษณา คำขอเว็บปกติอาจส่งที่อยู่ IP ข้อมูลเบราว์เซอร์หรืออุปกรณ์ URL ที่ร้องขอ และเวลาไปยัง GitHub และโครงสร้างพื้นฐานเพื่อส่งและปกป้องหน้าเว็บ คำขอไม่แนบภาพหน้าจอ รายการโปรด หรือเนื้อหาแอป GitHub อธิบายการประมวลผลใน GitHub Privacy Statement หากเว็บไซต์ใช้ไม่ได้ แอปจะแสดงสำเนาที่มีในแอป หากคุณเปิดลิงก์ซอร์สหรือใบอนุญาตของส่วนประกอบ เว็บไซต์นั้นอาจประมวลผลข้อมูลการเข้าชมทั่วไป คำขอไม่แนบภาพ ข้อความที่รู้จำ หรือเนื้อหาแอปอื่น

อีเมลสนับสนุน

หากส่งอีเมล เราจะได้รับที่อยู่อีเมล ข้อความ และข้อมูลที่คุณเลือกแนบ ใช้เพื่อตอบคำถาม แก้ปัญหา และปฏิบัติหน้าที่ที่เกี่ยวข้อง เก็บการติดต่อเท่าที่จำเป็นอย่างสมเหตุสมผลต่อวัตถุประสงค์เหล่านี้ ผู้ให้บริการอีเมลของคุณและของเราจัดการข้อความตามนโยบายของตน โปรดไม่ส่งภาพหน้าจอที่ละเอียดอ่อนเว้นแต่จำเป็น คุณขอให้ลบการติดต่อได้ ยกเว้นข้อมูลที่กฎหมายกำหนดให้เก็บ

ทางเลือกและการเปลี่ยนแปลง

คุณจัดการรายการโปรดในแอป สิทธิ์รูปภาพในการตั้งค่า iOS และสำเนาที่แชร์ในปลายทางได้ เราไม่เก็บเนื้อหาแอปบนเซิร์ฟเวอร์ผู้พัฒนา จึงกู้คืนหรือลบแทนคุณไม่ได้ เครื่องมือสำหรับผู้ใช้ทั่วไปนี้ไม่ได้ออกแบบมาเพื่อเก็บข้อมูลส่วนบุคคลของเด็ก หากวิธีจัดการข้อมูลเปลี่ยน เราจะปรับนโยบายและการเปิดเผยความเป็นส่วนตัวใน App Store วันที่ด้านบนระบุฉบับนี้

การซื้อและการตรวจสอบสิทธิ์

แอปใช้ Apple StoreKit ตรวจสอบธุรกรรมในอุปกรณ์และอ่านสิทธิ์ Pro พร้อมแชร์สถานะสิทธิ์สำหรับแสดงผลกับวิดเจ็ตในอุปกรณ์เดียวกัน ไม่สร้างบัญชีกับผู้พัฒนา ไม่ใช้การซื้อเพื่อติดตามข้ามแอป และไม่อัปโหลดภาพหรือการแก้ไขเพราะการซื้อ Apple จัดการบัญชี การชำระเงิน และประวัติธุรกรรมตามนโยบายของตน แอปไม่ได้รับรหัสผ่านบัญชี Apple หรือข้อมูลบัตรชำระเงินทั้งหมด

วิดเจ็ตบนหน้าจอโฮม

วิดเจ็ตแสดงภาพขนาดย่อ เวลา และจำนวนรายการส่งออกล่าสุดบนอุปกรณ์ สำเนาขนาดเล็กของภาพผลลัพธ์ที่ส่งออกล่าสุดสูงสุดสามภาพจะถูกแชร์กับส่วนขยายวิดเจ็ตบนอุปกรณ์นี้เพื่อแสดงบนหน้าจอโฮม ภาพต้นฉบับยังคงอยู่ในประวัติบนอุปกรณ์ การลบหรือล้างประวัติจะอัปเดตข้อมูลชุดนี้ ระบบเป็นผู้กำหนดเวลาการรีเฟรชการแสดงผล
