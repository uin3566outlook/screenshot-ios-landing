概要

ClipShare は iPhone で画像の撮影、切り取り、注釈、保存、共有を行うアプリです。本ポリシーは iOS アプリと公開の法的情報ページに適用されます。提供者は Huanwei Ye です。プライバシーに関するお問い合わせ先は airproductlab@gmail.com です。

画像とデバイス内処理

システムの写真ピッカーで選んだ画像や Capture and Share ショートカットから受け取った画像は、デバイス内で処理されます。切り取り、描画、テキスト、矢印、塗りつぶし、書き出しによって開発者のサーバーに画像がアップロードされることはありません。編集や共有に必要な作業ファイルは一時的に保存し、不要になると削除します。起動時には、15分以上経過した残存一時画像ファイルを削除します。明示的に写真に保存した画像や他のアプリに送ったコピーは、その保存先で管理できます。

カメラのアクセス権

「写真を撮る」を選んだときだけカメラのアクセス権を求めます。撮影後は直接エディタが開きます。元の写真は編集中のみメモリに保持され、写真や履歴には自動保存されません。エディタを閉じると解放されます。明示的に写真に保存した、または正常に共有した編集結果のみ、下記の規則に従って保存される場合があります。カメラ機能はマイクや位置情報へのアクセスを求めません。

写真のアクセス権

画像の選択には Apple のシステム写真ピッカーを使うため、写真ライブラリ全体へのアクセスは不要です。「写真に保存」をタップしたときだけ写真の追加専用権限を求め、編集済み画像をライブラリに保存します。iOS の設定で拒否や変更ができます。共有は引き続き利用できます。

画像の貼り付け

ホーム画面では Apple のシステム貼り付けボタンを使い、タップしたときに画像を受け取ります。ホーム画面ウィジェットの「貼り付けて編集」をタップすると、アプリが前面に移ってからクリップボードを読み取り、コピーした画像をエディタで直接開きます。iOS が他のアプリからの貼り付け許可を求める場合があります。通常の起動やアプリへの復帰ではクリップボードを自動で読み込みません。ウィジェット自体はクリップボードにアクセスしません。元画像は今回の編集のためにメモリ内で使用され、写真や履歴には自動保存されません。明示的に保存した、または正常に共有した編集結果のみ、上記の保存規則に従って保持される場合があります。貼り付けは写真やカメラの権限を求めません。

手動の塗りつぶしと保存済み注釈

モザイク、ぼかし、単色で手動で範囲を隠せます。画像編集はデバイス内で行われます。自動の塗りつぶしは現在利用できず、画像のスキャンや個人情報識別モデルの実行は行いません。以前保存した範囲や確認状態は、編集可能な注釈として保持されます。お気に入りには種類、座標、確認状態が保存される場合がありますが、認識した元のテキストは含まれません。履歴には、下記の保存規則に従って注釈を合成した編集済み画像を保存します。

デバイスに保存される情報

外観設定、クイック撮影の設定状態、作成したお気に入りをアプリのローカル領域に保存します。お気に入りには切り取り座標、注釈効果、名前、入力したテキストが含まれる場合がありますが、元画像は含まれません。共有完了時や写真への保存時には、編集済み画像をデバイス内の非公開の履歴にも保存します。履歴の容量は100 MBで枚数制限はなく、容量を超えると古い画像から削除します。アプリ内で個別に削除することもできます。開発者はこれらの内容を受け取りません。お気に入りは設定から削除できます。アプリを削除すると、iOS の動作に従ってローカル領域も削除されます。履歴やアプリを削除しても、写真や他の共有先に保存済みのコピーは削除されません。

共有と第三者

共有をタップすると、iOS が利用可能な共有先を表示します。編集済み画像は選んだ共有先にだけ送られ、その提供者の規約とプライバシーポリシーに従って処理されます。ClipShare は受信者の一覧を保存しません。アカウントシステム、広告、第三者の分析 SDK、アプリ間トラッキングは使用していません。

公開の法的情報ページ

アプリは GitHub Pages から HTTPS 経由で最新のプライバシーポリシーと利用規約を読み込むことができます。開発者はこれらのページに Cookie、フォーム、分析スクリプト、広告を追加していません。ページの配信と保護のため、通常の Web リクエストにより IP アドレス、ブラウザやデバイスの情報、URL、時刻が GitHub とそのインフラに伝わる場合があります。スクリーンショット、お気に入り、アプリの内容はリクエストに添付されません。GitHub による処理は GitHub Privacy Statement に記載されています。サイトを利用できない場合はアプリ内のコピーを表示します。コンポーネントのソースやライセンスのリンクを自ら開いた場合、リンク先が通常のアクセス情報を処理することがあります。そのリクエストに画像、認識テキスト、その他のアプリ内容は含まれません。

サポートメール

サポートにメールすると、メールアドレス、本文、任意で添付した情報を受け取ります。回答、問題解決、適用される義務の履行のために使用し、その目的に合理的に必要な期間だけ保管します。送受信のメールサービスはそれぞれのポリシーに従って処理します。必要な場合を除き、機密性のあるスクリーンショットを送らないでください。法令で必要な保存を除き、やり取りの削除を求めることができます。

選択肢とポリシーの変更

お気に入りはアプリ内、写真のアクセス権は iOS の設定、共有済みコピーは選んだ保存先で管理できます。開発者のサーバーにアプリの内容を保持していないため、代わりに取得や削除はできません。この一般向けのユーティリティは、子どもの個人情報を収集するために設計されていません。データの取り扱いが変わる場合は、本ポリシーと App Store のプライバシー開示を更新します。上記の日付がこの版を示します。

購入と利用権の確認

Apple StoreKit を使ってデバイス内で購入を検証し、Pro の利用権を確認します。同じデバイスのウィジェットと利用権の表示状態を共有します。開発者アカウントの作成、購入を使ったアプリ間トラッキング、購入に伴う画像や編集内容のアップロードは行いません。Apple は自社のプライバシーポリシーに従ってアカウント、支払い、取引記録を処理します。アプリは Apple Account のパスワードや決済カードの完全な情報を受け取りません。
